# 📚 Periodic Publications System

A web application for managing subscriptions to periodic publications.  
Users can browse, search, and subscribe to various publications, while administrators manage the catalog and users.

---

## 🚀 Features

### For Readers
- Register and log in to the system
- Browse publications:
  - Sort by **title** or **price**
  - Filter by **category**
  - Search by **title**
- Manage subscriptions to publications
- View personal subscriptions in a **Personal Cabinet**
- **Top up balance**
- **Pay for subscriptions** from the account

### For Administrators
- Add, edit, or delete publications
- Block or unblock users
